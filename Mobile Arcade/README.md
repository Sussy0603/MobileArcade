# MOS Mobile Arcade

Our mobile games (also on Google Play), playable in the browser.

- index.html / arcade.js / theme-boot.js / fonts — the page (same look as the first Arcade)
- games.json — the game list (name, description, category)
- games/<slug>/ — one folder per game
- shots/<slug>.jpg — one picture per game

To add a game: copy its www folder into games/<slug>/, add a line in games.json, add shots/<slug>.jpg.
